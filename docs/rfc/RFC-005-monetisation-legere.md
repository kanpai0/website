# RFC-005 — Monétisation légère (liens d'achat affiliés)

**Statut** : Ouverte

## Contexte

Le README liste « liens d'achat affiliés, monétisation légère » dans son bloc
« V2 si le projet évolue ». `docs/retrospective-manques.md` (tableau « Ce qui
est délibéré et non un manque ») confirme : « Monétisation absente — Déplacée
en v2 optionnelle, pour amortir les coûts si besoin ». Le projet est un outil
personnel en premier lieu ; aucune validation d'audience externe n'est
requise en v1.

Ce n'est pas non plus une idée tardive : `BRIEF.md` (commit `4597ac9`,
2026-03-23) listait déjà Stripe Payment Links, Snipcart et les liens
affiliés comme options de monétisation v1 envisageables. Le report en v2 est
donc un choix de séquencement délibéré, pas un oubli découvert après coup.

## Pistes envisagées (non tranchées)

Aucune piste concrète n'a été formalisée au-delà de la mention « liens
d'achat affiliés » — pas de programme d'affiliation identifié, pas
d'emplacement UI envisagé.

## Déclencheur de réouverture

1. L'audience devient mesurable (au-delà du cercle personnel de l'auteur).
2. Une décision explicite de monétiser le projet est prise — actuellement hors périmètre v1 par choix délibéré, pas par oubli.

Source : README.md (§ « V2 si le projet évolue ») ; docs/retrospective-manques.md (§ « Ce qui est délibéré et non un manque »).
